Olá! Este é um projeto pessoal que estou desenvolvendo com o objetivo de facilitar o controle e a visualização de finanças pessoais, a partir de dados simples, como uma planilha do Excel.

Muitas pessoas (inclusive eu) utilizam planilhas para registrar gastos e ganhos mensais. A ideia deste projeto surgiu da seguinte pergunta:

E se, além da planilha, fosse possível visualizar esses dados de forma clara, com gráficos, comparações e simulações financeiras?

💡 O que o sistema faz

A partir de uma planilha de registros financeiros, o sistema permite:

📈 Visualizar gráficos de gastos por mês

📊 Comparar gastos com meses anteriores

🔄 Analisar a evolução financeira ao longo do tempo

🧮 Simular valores de gastos e ver o impacto no saldo e no total mensal

🖥️ Utilizar tudo isso em uma interface gráfica simples e funcional

Tudo é pensado para ser claro, direto e adaptável ao contexto do usuário.

🛠️ Tecnologias utilizadas

O sistema foi desenvolvido em Python, utilizando as seguintes bibliotecas:

Pandas → tratamento e análise de dados

Matplotlib → geração de gráficos

CustomTkinter → interface gráfica moderna e funcional

🧩 Estrutura do projeto

O sistema está dividido em três módulos principais:

Main

Responsável por iniciar o sistema

Recebe a planilha do usuário

Faz a comunicação entre os módulos

Financeiro

Realiza o tratamento dos dados

Executa operações matemáticas e análises

Gera os resultados financeiros

Interface

Exibe os dados e gráficos para o usuário

Organiza botões, textos e elementos visuais

Recebe os dados já processados do módulo financeiro

🎯 Objetivo do projeto

O foco principal é o controle de gastos pessoais, mas o sistema pode ser facilmente adaptado para outros cenários, como:

Controle financeiro familiar

Pequenos empreendedores

Pequenas lojas ou e-commerces
